> [!WARNING]
>
> ### Антивирусные срабатывания
> WinDivert иногда вызывает реакцию антивируса.  
> Это инструмент перехвата и фильтрации трафика, необходимый для работы zapret.
> Его могут использовать как безопасные, так и вредоносные программы, однако сам WinDivert вирусом не является.
>
> **Фрагмент из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов классифицирует файлы WinDivert как инструменты повышенного риска или хакерские утилиты, после чего удаляет их и помещает в карантин. В таком случае обнаружение обычно называется `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте каталог с zapret в исключения антивируса либо отключите проверку PUA — потенциально нежелательных приложений. Например, в Kaspersky есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы уверенно понимаете настройку исключений, предпочтительно создать исключение. В противном случае рекомендуется отключить обнаружение PUA.

## ⚙️ Использование

1. Включите Secure DNS.
   * В Chrome активируйте "Использовать безопасный DNS" и выберите поставщика, отличного от "Поставщика по умолчанию".
   * В Firefox откройте "DNS через HTTPS", выберите режим "Персональный", затем "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован.
   * Windows 11 позволяет включить Secure DNS непосредственно в настройках системы — [инструкция](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот способ рекомендуется.
   * На роутерах Keenetic включите параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать неправильно.

2. Загрузите zip- или rar-архив с [последнего релиза](https://github.com/apexmakermarch/zapret-discord-youtube/releases/latest).

3. Откройте свойства скачанного архива и установите флажок "Разблокировать". При использовании 7-Zip или PeaZip этот шаг можно пропустить.

4. Распакуйте архив в путь без кириллицы и специальных символов.

5. Запустите нужный файл.
   * Для поиска рабочей стратегии откройте **`service.bat`** → `Run Tests` → `Standard tests` → `All configs`.
   * Чтобы добавить стратегию в автозапуск, выберите **`service.bat`** → `Install Service` → подходящую стратегию.

## ℹ️ Кратко о файлах

- [**`general.bat ...`**](./general.bat) запускает стратегию вручную.

  Такой запуск удобен для проверки стратегий. Результат зависит от множества условий, поэтому **перебирайте варианты ALT, FAKE и другие, пока не найдёте подходящий**.

- [**`service.bat`**](./service.bat) отвечает за автозапуск и дополнительные операции:
  - <ins>**`Install Service`** — добавление выбранной стратегии в автозапуск через services.msc.</ins>
  - **`Remove Services`** — удаление стратегии и WinDivert из служб.
  - **`Check Status`** — проверка обхода и состояния служб, включая автозапущенную стратегию и WinDivert.
  - **`Game Filter`** — смена режима обхода для игр и других сервисов, работающих по UDP и TCP на портах выше 1023.  
    **После смены параметра стратегию нужно перезапустить.**  
    В скобках отображается текущее состояние — включено или выключено.
  - **`IPSet Filter`** — включение или отключение обхода для сервисов из `ipset-all.txt`.  
    Это может помочь при проверке ресурса, который без zapret работает, а с ним — нет.  
    В скобках показывается состояние:
    - `none` — IP-адреса не проверяются;
    - `loaded` — адрес проверяется на наличие в списке;
    - `any` — под фильтр попадает любой IP-адрес.
  - **`Auto-Update Check`** — включение или отключение автоматической проверки обновлений.
  - **`Replace active fakes`** — замена используемого фейка на другой из каталога `bin`.
  - **`Update IPSet List`** — загрузка актуального `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** — обновление hosts <ins>для восстановления веб-версии Telegram и подключения к голосовому чату Discord.</ins>
  - **`Check for Updates`** — ручная проверка обновлений.
  - **`Run Diagnostics`** — поиск распространённых причин неисправности zapret.  
    В конце можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает, если он внезапно перестал работать.
  - **`Run Tests`** — запуск проверки стратегий:
    - `Standard tests` — тестирование сайтов из `utils/targets.txt`;
    - `DPI checkers` — проверка DPI у разных провайдеров, включая Cloudflare и Amazon.

## ☑️ Частые вопросы и проблемы

### После запуска `general*` ничего не происходит

При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe, который виден на панели задач.  
Если этого не произошло, обратитесь к [#522](https://github.com/apexmakermarch/zapret-discord-youtube/issues/522).

### Не подошла ни одна стратегия

1. Откройте командную строку от имени администратора.
2. Выполните по очереди:

   `netsh winsock reset`

   `netsh int ip reset all`

   `netsh winhttp reset proxy`

   `ipconfig /flushdns`

3. Перезагрузите компьютер.

### Не открывается Telegram в браузере

Откройте **`service.bat`** и выберите **`Update hosts file`**. Если hosts устарел, программа предложит обновить его вручную:

- скопируйте весь текст из открывшегося блокнота;
- откройте текстовым редактором от имени администратора файл `hosts` в появившейся папке;
- добавьте скопированный текст в конец `hosts` или замените ранее добавленный аналогичный фрагмент;
- сохраните файл и проверьте подключение. Если результата нет, убедитесь, что `hosts` действительно сохранился.

#### Работа не гарантируется. Если это не помогло, используйте [Desktop-версию Telegram](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/apexmakermarch/tg-ws-proxy) или любым публичным прокси.

### Обход не работает или перестал работать

> [!IMPORTANT]
> **Стратегии могут со временем перестать работать.**
> Обнаружение конкретной стратегии способно произойти не сразу: вариант, который некоторое время работал, позже может перестать помогать.
> Здесь собрано много стратегий. Если готовые варианты не подходят, создайте новую на основе одной из них, изменив параметры. Описание параметров доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- В `service.bat` → `Run Diagnostics` проверьте, нет ли ошибок.
- Убедитесь, что ресурс указан в списках доменов или IP-адресов.
- Проверьте другие варианты, включая **`ALT`**, **`FAKE`** и прочие стратегии.
- Выполните полную переустановку по инструкции ниже.
- См. [#765](https://github.com/apexmakermarch/zapret-discord-youtube/issues/765).

### Полная переустановка или обновление

- Сохраните добавленные вами ресурсы и данные.
- Перезапустите устройство.
- Выполните `service.bat` → `Remove Services`.
- Запустите `service.bat` → `Run Diagnostics`; устраните найденные ошибки и в конце выберите Y.
- Удалите каталог zapret.
- Скачайте свежую версию со [страницы релизов](https://github.com/apexmakermarch/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`).
- Нажмите ПКМ по архиву → свойства. Если внизу справа есть "Разблокировать", установите флажок, нажмите "Применить" и "ОК".
- Распакуйте архив в новую папку в корне диска, без пробелов и специальных символов.
- Запускайте разные `general`-скрипты и проверяйте сайты. Если интернет-ресурсы не открываются, закройте программу через значок замка на панели задач и попробуйте другую стратегию.
- После выбора рабочего варианта добавьте его в автозапуск: `service.bat` → `Install Service` → нужная стратегия.

### Игра или приложение не работает при включённом zapret

Проверьте в `service.bat`, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит сообщает о WinDivert

Инструкция доступна здесь: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

Замените `WinDivert.dll` и `WinDivert64.sys` в [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert остаётся среди служб

1. Узнайте имя службы в командной строке Windows, открытой через Win+R → `cmd`:

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование).
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Переберите остальные стратегии, особенно если раньше всё работало.
- Дополнительная информация есть в [#251](https://github.com/apexmakermarch/zapret-discord-youtube/discussions/251).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включён [Secure DNS](#%EF%B8%8Fиспользование).
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить её.
- В `service.bat` выберите `Run Diagnostics` и очистите кэш Discord.
- Проверьте приложение Discord после очистки.
- Откройте Discord в браузере: https://discord.com/app. Если браузерная версия работает, можно пользоваться ею.
- Если Discord не работает и в браузере, снова проверьте все стратегии: YouTube и Discord могут работать на разных вариантах.
- См. также [#252](https://github.com/apexmakermarch/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Используйте [tg-ws-proxy](https://github.com/apexmakermarch/tg-ws-proxy).
- Либо подключите бесплатный MTProto-прокси из интернета.

### Не запускаются игры

Игр много, поэтому проверить и исправить каждую из них невозможно.

Попробуйте универсальную последовательность:

- через `service.bat` обновите ipset и включите `Game Filter`;
- если это не помогло, дополнительно включите `ipset any`.

Учтите: `ipset any` может нарушить открытие многих сайтов. Не оставляйте этот режим включённым постоянно. Определите все IP-адреса, используемые игрой, и внесите их в `ipset-all.txt`.

Если результат отсутствует, создайте обсуждение в разделе [Discussions](https://github.com/apexmakermarch/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Не нашли подходящего ответа

Создайте обращение [здесь](https://github.com/apexmakermarch/zapret-discord-youtube/issues).

## 🗒️ Добавление адресов других ресурсов

Расширить список обхода можно через следующие файлы:

- **`list-general-user.txt`** — домены; поддомены учитываются автоматически;
- **`list-exclude-user.txt`** — домены, которые нужно исключить, например когда IP-сеть есть в `ipset-all.txt`, но конкретный домен из неё фильтровать не требуется;
- **`ipset-all.txt`** — IP-адреса и подсети;
- **`ipset-exclude-user.txt`** — IP-адреса и подсети для исключения.

Файлы **`*-user.txt`** автоматически появляются при первом запуске `zapret` или `service.bat`.
